# Lost & Found Portal

A web-based Lost & Found Portal that allows users to report lost and found items, manage item records, and find potential matches between lost and found items.

## Features

- User registration
- User login
- Add lost and found items
- Upload item images
- View all reported items
- Search and filter items
- Edit and delete item records
- Mark lost items as found
- Mark found items as claimed
- Smart matching between lost and found items
- Match scoring based on:
  - Category
  - Location
  - Brand
  - Color
  - Common keywords
- Google Maps location integration

## Tech Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL

### APIs / Services
- Google Maps
- Google Sign-In
